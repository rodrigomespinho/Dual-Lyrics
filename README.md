# Dual-Lyrics
Aprenda inglês ouvindo música! Este site exibe a letra sincronizada com a música, em inglês e português lado a lado, para você entender cada frase em tempo real. Conta ainda com revisão inteligente de vocabulário, exercícios e várias ferramentas de estudo. Aprender nunca foi tão natural: ouça, entenda, revise e evolua.
